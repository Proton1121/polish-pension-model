# polish-pension-model

Open-source stochastic model of the Polish pension system (ZUS + PPK).

> **Status:** early stage — no code yet.

## Scope (planned)

- **ZUS** — the public, defined-contribution (NDC) pillar: contributions, indexation, and benefit calculation.
- **PPK** (Pracownicze Plany Kapitałowe) — the employee capital plans: contributions, subsidies, and investment returns.
- **Stochastic simulation** of key uncertainties (wages, inflation, returns, longevity) to produce distributions of outcomes rather than single-point estimates.
